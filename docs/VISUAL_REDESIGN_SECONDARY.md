# Admin, Workout and Physio redesign

Scope: approved master sections 40–44. Baseline `8449def`. No live account, workout, case or source mutations. Isolated fixture servers only for implementation QA.

## Findings and plan

- Admin live Chrome inspection confirms action overload, an orphan eleventh metric, cramped deployment labels, and equal visual priority across all data. Recompose into a title/utility header, export disclosure, reporting-period controls, four principal metrics, supporting operational totals, and a clearly labeled service-health group. Preserve calculator, credit, chart and table semantics; use shared selectors and maintenance confirmation.
- Workout source/live audit confirms a narrow desktop phone column, muscle names constrained to 34px and sheet body height exceeding its parent. Adapt Today, Progress, Routines and Settings into deliberate desktop grids, retain mobile navigation/logger, correct progress-label space, use a flex sheet with scrolling body/sticky submit, and adopt shared calendar/confirmation controls. Preserve offline drafts and sync behavior.
- Workout shares need readable title/body/technique text, balanced exercise/metric surfaces, coherent unavailable recovery and print layout.
- Cloud Physio launcher needs a compact title, explicit local-connection status/action hierarchy and readable startup disclosure. Its omitted auth bootstrap explains why shared-shell authentication needs investigation; add the same bootstrap sequence used by authenticated app pages without changing companion access.
- Local Physio needs consistent typography instead of mixed serif headings, a compact region rail, intentional mobile reflow, readable source/list/detail proportions, shared selectors/dates/case forms/confirmation, and polished reader/deep-search/media dialogs. Keep case/source data local and retain explicit Codex submission semantics.

## Implemented

- Admin: compact title and export disclosure, four principal metrics with a supporting totals strip, readable deployment values, ordered service health, shared selectors and maintenance confirmation. Fixed intrinsic table width expanding mobile panels. Batch stage labels now omit duplicated case-insensitive status text.
- Workout: desktop navigation and purpose-built grids for Today, Routines, Progress and Settings; useful empty schedule; readable muscle labels and trend markers; bounded logger width and legible set selectors. Sheets now have a scrolling body and reachable action; dates and destructive/unsaved confirmations use shared controls. Opening a sheet clears stale toast feedback.
- Shares: recognizable branding, larger reading text, aligned exercise/summary cards, unavailable recovery link and print rules.
- Cloud Physio: two-column connection workspace, contextual status/actions, startup disclosure, reliable checking/disabled state, and the shared authentication bootstrap. Fixture authentication renders the signed-in shell; this does not prove the cause of every previously observed live authentication disagreement.
- Local Physio: coherent three-pane desktop composition and mobile region/type navigation, compact body-map disclosure, shared case/source selectors, website calendar, shared create/delete dialogs, more readable note/source layouts and deep-search/media dialog motion. Preserved local data and existing search/AI semantics.
